# autobathcdoser

Yes, this repo name is a typo. It's only kept for historical purposes.

Some early Auto Batch Doser units were flashed with a config that pointed ESPHome's "Take Control" at `Chill-Division/autobathcdoser` instead of [Chill-Division/autobatchdoser](https://github.com/Chill-Division/autobatchdoser), so adopting them failed.

The `autobatchdoser.yaml` in here is tagged `v1`, because that's what those units ask for. It's the v2 config from the correct repo, so once a unit has been adopted and updated it points to [autobatchdoser v2](https://github.com/Chill-Division/autobatchdoser/tree/v2) and never comes back here.

Don't use this repo for anything else.
